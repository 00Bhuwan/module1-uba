## To install python

goto [python.org]


## Virtual Environment

### To create 
> python -m venv <path>

if inside a folder use
> python -m venv <ins>envname</ins>

### To activate 
> <ins>envname</ins>\Scripts\activate

### To deactivate
> deactivate

## To delete
> rm -r <ins>envname</ins>

<all the artifacts should be removed along the directory>
